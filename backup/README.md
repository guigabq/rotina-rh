# Backup das rotinas e das skills

Esta pasta é só uma cópia de segurança dos textos das rotinas e das skills deste assistente. As rotinas não leem `backup/`: o que está aqui não entra no contexto delas e não aumenta o custo da execução.

Não grave senha, token, e-mail nem dado pessoal nesta pasta. Onde o texto original cita pessoa, conta ou endereço, a cópia usa marcadores (`<GESTOR>`, `<EMAIL_RH>`, `<EMAIL_REMETENTE>`, `<FUNCIONARIO>`).

Atualize esta pasta somente quando uma rotina ou uma skill mudar.
